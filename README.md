# RootMyVivo

Root для vivo и iQOO с залоченным загрузчиком. Без разблокировки, без прошивки boot — поставил APK, нажал кнопку, подождал.

В основе GhostLock (CVE-2026-43499, use-after-free в futex PI) + установка KernelSU поверх временного рута.

[English](README.en.md) · [中文](README.zh.md)

## Как это выглядит

1. Ставишь [APK из релизов](https://github.com/zenyxx-xd/RootMyVivo/releases)
2. Запускаешь Shizuku (один раз, для shell-доступа) или поднимаешь ADB по TCP
3. Жмёшь «Получить ROOT» — приложение само находит пейлоад под твоё ядро, скачивает и гонит эксплойт
4. После рута ставится KernelSU (выбор из четырёх менеджеров), рут живёт до перезагрузки
5. Перезагрузился — жмёшь кнопку ещё раз, или включи автозагрузку в настройках, тогда эксплойт перезапустится сам

Да, возможны паники ядра. Это нормально: телефон просто перезагрузится и попробуешь снова. Тайминговая лотерея, а не брик.

## Что умеет

- Определение устройства, версии ядра и KMI без root
- Подбор пейлоада по полному имени ядра (одна модель бывает на разных сборках ядра — они различаются)
- Живой лог эксплойта прямо в приложении, история последних запусков
- Восстановление рута после перезагрузки телефона (фоновый перезапуск эксплойта)
- «Перезапустить эксплойт» при живом руте — если рут есть, а KernelSU не встал
- Обновление приложения изнутри: проверка после каждого запуска, плашка с кнопкой, скачивание с прогрессом, системный установщик
- Экран «Поддерживаемые устройства» — весь каталог пейлоадов, что найдётся для твоей модели

## Поддерживаемые устройства

Полный и всегда свежий список лежит в [RootMyVivo-Payloads](https://github.com/zenyxx-xd/RootMyVivo-Payloads) — приложение тянет его оттуда при каждом запуске.

Проверенные на железе:

| Устройство | Ядро | Статус |
|---|---|---|
| iQOO Neo 11 (PD2520) | 6.6.89 / 6.6.127 | проверено автором |
| iQOO Z10 Turbo Pro (PD2453) | 6.6.89 | работает у пользователей |

Собранные порты (нужна проверка на железе): iQOO 13 (India), iQOO Neo10 Pro, vivo X200, vivo X200 Pro.

Ядро должно быть без фикса CVE-2026-43499: для 6.6 это всё до 6.6.139, для 6.1 — до 6.1.144. Если сборка `6.6.140+` — увы.

## Транспорт

Первый запуск: Shizuku в режиме ADB (беспроводное сопряжение, без ПК). После первого рута приложение закрепляет ADB по TCP на 5555 и дальше Shizuku не нужен.

## Сборка

```sh
./gradlew :app:assembleRelease
```

JDK 17+, SDK 35. Подпись — своя, ключи в репо не лежат.
